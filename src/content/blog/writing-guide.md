## Write a post

Create a Markdown file in `src/content/blog/`. Set a title, description, date,
language, and tags in the frontmatter above. Keep `draft: true` while writing;
change it to `false` when the article is ready to publish.

## Add figures and code

Put image files in `public/media/blog/` and reference them with Markdown images.
Use fenced code blocks with a language name for syntax highlighting.

This guide is a draft and is excluded from the blog list, article routes, and sitemap.
